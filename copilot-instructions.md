# Acessibilidade neste repositório

- Use as Skills em `.github/skills/` para tarefas especializadas de acessibilidade.
- Relacione uma afirmação WCAG a evidência observável e à fonte oficial; sinalize quando o vínculo for apenas provável.
- Não afirme conformidade com base apenas em scanner, código estático ou ausência de violações.
- Separe violações confirmadas, itens para revisão, sugestões e aspectos não avaliados.
- Preserve HTML nativo e padrões existentes do projeto quando recomendar ou propor uma mudança.
- Peça revisão humana para conteúdo, significado, fluxos completos e resultados de tecnologia assistiva.
